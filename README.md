# androiddevtools-plugin-repo

Distribution repository for the [AndroidDevTools](https://github.com/hacket/AndroidDevToolsPlugin) IntelliJ plugin.

## Install

Android Studio / IntelliJ → Settings → Plugins → ⚙ → Manage Plugin Repositories → add:

```
https://hacket.github.io/androiddevtools-plugin-repo/updatePlugins.xml
```

Then search "AndroidDevTools" in the Marketplace tab and install.
The plugin zip is unsigned — accept the warning dialog on install.
